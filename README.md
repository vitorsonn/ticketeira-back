# Ticketeira

> Gestão de eventos

## 📌 Sobre o projeto
A ticketeira foi inicialmente pensada como um sistema de gestão completa que envolve eventos, a venda e controle da quantidade de ingresso, e o acompanhamento das métricas, além da sessão de usuários, que permite a compra dos eventos disponíveis, pagamentos via Stripe e QR Code para autenticar o ingresso. Separado em interface de administração e de usuários que querem procurar os eventos e se inscrever com poucos cliques, além de possuir um sistema de QR Code que realiza a autorização dos tickets para a entrada no evento.

### Problema

Qual problema motivou a criação do sistema?
A falta de um sistema simples porém completo que faz a gestão dos eventos locais, garantindo a disponibilidade e controle da quantidade de ingressos, além de possuir uma interface fluída para os usuários acessarem facilmente e comprar seus ingressos após ver todas as informações de cada evento.

- Quem tinha esse problema? Pequenas organizações de eventos locais.
- Como esse problema era resolvido antes? Provavelmente as organizações precisavam tercerizar esse trabalho de controle e compra de ingressos.
- Por que vale a pena resolvê-lo? Trazer a oportunidade dessas organizações terem seu próprio sistema, evitar custos de terceiros e mesmo assim ter controle das suas operações relacionados a gestão de eventos. 

### Solução

Explique de forma simples o que o sistema faz para resolver o problema.
Possui administração de eventos com funcionalidades de cadastro, remoção e alteração, controle de quantidade de ingressos por diferentes setores, localização e breve descrição.
Para não parar apenas na administração, também possui a versão de usuário, que é possível procurar por eventos disponíveis e realizar a compra, pós verificação da disponibilidade dos ingressos por setor.
A integração do gateway de pagamento Stripe, deixa tudo mais centralizado e fácil para o usuário realizar a transação e receber seu QR Code para autenticar seu ticket na entrada do evento.
### Objetivo

O que pretendíamos alcançar com o projeto?
Garantir a eficiência das pequenas organizações de eventos locais e seu alcance sendo amplamente distribuído
